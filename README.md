# Задание №2. Вариант 4. Коды Грея

## Задание

В файле `main.py` реализовать функцию:

- `gray_code` — рекурсивная генерация полного $n$-разрядного кода Грея зеркальным построением.

Функция принимает число разрядов и возвращает все $2^n$ слов этого кода. Слово — список длины $n$ из целых чисел $0$ и $1$. Бит, добавленный при переходе к длине $n$, стоит первым элементом списка.

При $n=1$ функция возвращает $[[0], [1]]$. При $n>1$ список состоит из двух половин. Сначала идут слова кода длины $n-1$, к каждому из которых спереди добавлен $0$. Затем те же слова идут в обратном порядке, и к каждому спереди добавлена $1$.

Если аргумент не является целым числом не меньше $1$, функция выбрасывает исключение.

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

**Равномерный двоичный код** — набор слов одной длины, составленных из $0$ и $1$. Полный $n$-разрядный код содержит $2^n$ слов: столько же, сколько двоичных наборов длины $n$.

**Стандартная нумерация Грея** перечисляет все эти слова так, что любые два соседних, а также последнее и первое, отличаются ровно в одном разряде. Расстояние Хэмминга между ними равно $1$. Такой порядок задаёт гамильтонов цикл на $n$-мерном единичном кубе: вершины куба — двоичные слова, ребро соединяет слова, различные в одном разряде.

**Зеркальное построение.** $G(n)$ — упорядоченный список слов длины $n$, $rev$ — тот же список, записанный задом наперёд. Запись $0\cdot w$ означает слово $w$ с нулём впереди, $1\cdot w$ — слово $w$ с единицей впереди.

$$
G(n)=\bigl(0\cdot G(n-1),\; 1\cdot rev(G(n-1))\bigr),
\qquad
G(1)=\bigl([0],\,[1]\bigr).
$$
